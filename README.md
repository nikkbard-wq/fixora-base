# FIXORA — Product & Platform Architecture Portal

**FIXORA Architecture Baseline v0.1**

Интерактивный многостраничный портал архитектуры FIXORA SaaS ERP Platform.

Портал объясняет:
- Platform Core и Control Plane
- Organization, Identity & Access
- Subscriptions, Entitlements, Feature Flags, Usage
- Business Capabilities, Domain Modules, Industry Solutions
- Events, AI/OCR, Integrations, Audit & Storage
- Security, Dependencies, Deployment и Roadmap

Сайт публикуется автоматически через GitHub Pages.
